# Captures d'écran — KineVision AI

Pour ajouter les captures d'écran de KineVision AI au portfolio :
1. Déposez vos fichiers `.png` ou `.webp` dans ce dossier (`public/projects/kinevision/`), par exemple :
   - `01-dashboard.png`
   - `02-camera-ai.png`
   - `03-rehab-websocket.png`
   - `04-progress-gamification.png`
   - `05-chat-kine.png`
2. Dans `src/data/projects.ts`, renseignez le tableau `screenshots` du projet `kinevision-ai` avec ces chemins (`/projects/kinevision/01-dashboard.png`, etc.).
Le portfolio remplacera automatiquement le visuel interactif d'aperçu par votre galerie de captures réelles.
